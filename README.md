# SoluTI · Soluciones Tecnológicas Integrales

Página web de SoluTI, desarrollo de software a medida desde Loncoche, Región de La Araucanía.

## Uso local (Laragon)

1. Copiar la carpeta en `C:\laragon\www\portafolio`.
2. Iniciar Laragon y abrir `http://portafolio.test`.

Requiere PHP 8.0 o superior. No usa base de datos.

## Editar contenido

Todos los textos (servicios, soluciones, contacto, titular) están en `config.php`.

| Archivo | Contenido |
| --- | --- |
| `config.php` | Textos y datos de contacto |
| `index.php` | Estructura de la página |
| `assets/style.css` | Diseño y animaciones |
| `assets/app.js` | Efectos (titular que se escribe, aparición al hacer scroll, contadores) |
| `assets/copihue.svg` | Ícono del copihue |
